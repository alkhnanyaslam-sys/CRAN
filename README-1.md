# CRWN — Streetwear Store

مشروع متجر CRWN كامل: باك إند (Node.js + Express) وفرونت إند (HTML/CSS/JS عادي، من غير أي framework).

## هيكل المشروع

```
crwn-project/
├── backend/
│   ├── server.js              ← نقطة تشغيل السيرفر
│   ├── package.json
│   ├── .gitignore
│   ├── routes/
│   │   ├── products.js        ← عرض/إضافة/حذف المنتجات
│   │   ├── orders.js          ← إنشاء الطلبات وعرضها للأدمن
│   │   └── auth.js            ← دخول الأدمن بالرقم السري
│   ├── middleware/
│   │   └── adminAuth.js       ← حماية مسارات الأدمن
│   ├── utils/
│   │   └── db.js              ← قراءة/كتابة ملفات JSON
│   └── data/
│       ├── products.json      ← قاعدة بيانات المنتجات
│       ├── orders.json        ← قاعدة بيانات الطلبات
│       └── settings.json      ← الرقم السري وتوكن الدخول
│
└── frontend/
    ├── index.html              ← صفحة المتجر
    ├── admin.html               ← صفحة لوحة التحكم
    ├── css/
    │   └── style.css
    └── js/
        ├── api.js               ← الاتصال بالباك إند
        ├── store.js              ← منطق المتجر والسلة والدفع
        └── admin.js              ← منطق لوحة التحكم
```

## تشغيل المشروع محليًا

```bash
cd backend
npm install
npm start
```

السيرفر هيشتغل على `http://localhost:4000` وهيقدم الفرونت إند تلقائيًا من نفس البورت (يعني تقدر تفتح `http://localhost:4000` وتلاقي المتجر شغال، ولوحة التحكم على `http://localhost:4000/admin.html`).

الرقم السري الافتراضي للوحة التحكم: **2580** — غيّره أول حاجة من تبويب "الإعدادات".

## الرفع على GitHub

ارفع الملفين `backend/` و `frontend/` بنفس الأسماء والمسارات دي بالظبط جوه الريبو، عشان الروابط بين الملفات (زي `<script src="js/api.js">`) تفضل شغالة زي ما هي.

## النشر (Deployment)

- **الفرونت إند**: أي استضافة ملفات ثابتة تنفع (GitHub Pages، Vercel، Netlify).
- **الباك إند**: لازم استضافة بتشغّل Node.js باستمرار (GitHub Pages وحده مش هيشغّله لأنه استضافة ثابتة فقط). خيارات مجانية للبداية: Render أو Railway أو Cyclic.
- لو استضفت الباك إند على دومين مختلف عن الفرونت إند، غيّر قيمة `API_BASE` في ملف `frontend/js/api.js` لرابط الباك إند بتاعك.

## ملاحظة عن طرق الدفع

طرق الدفع الحالية (كاش عند الاستلام، فودافون كاش، InstaPay، فوري) بتسجل اختيار العميل مع الطلب فقط. لتفعيل خصم إلكتروني حقيقي وقت الطلب، هتحتاج تتعاقد مع بوابة دفع مصرية زي Paymob أو Fawry Pay أو Kashier بعد تسجيل نشاطك التجاري، وتربط مفاتيح الـ API بتاعتهم في `backend/routes/orders.js`.
